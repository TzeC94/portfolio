Overview

Project context

  • Open-source experimental Unity FPS template focused on Mirror Networking server/client authority.
  • Built by converting Unity’s First Person Starter Assets into a networked FPS foundation.
  • Designed as a learning and prototyping project for multiplayer FPS features rather than a finished commercial game.
  • Repository is licensed under Apache-2.0, making it useful as a reference or starting point for other developers.

Core systems

Implemented features

  • Simple networked player movement
  • First-person player model and third-person view model
  • Simple weapon system with shooting, reload, hold-to-fire, animation handling, and effect handling
  • Pickup and inventory system with item outline, inventory UI, drag-and-drop, and weapon slot support
  • Simple health system and hit information
  • Damage popup usage
  • Procedural level system
  • Mirror Networking integration around FPS Starter Assets

Value

Why it matters

This project shows Tze Chian’s practical interest in reusable multiplayer architecture, authority models, and converting single-player starter assets into a network-ready FPS foundation. It also demonstrates initiative outside employment work: documenting systems publicly, sharing code under an open-source license, and building a template that other Unity developers can study, modify, or extend.
