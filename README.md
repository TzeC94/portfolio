# Teoh Tze Chian Portfolio Website

Static multi-page portfolio website with a rugged Rust Console Edition-inspired visual direction.

## Structure

- `index.html` — homepage with short project highlight cards
- `projects/*.html` — dedicated project case-study pages
- `style.css` — responsive styling and visual direction
- `script.js` — mobile nav and reveal animation
- `assets/*-promo.png` — portfolio-friendly project visuals used across the site
